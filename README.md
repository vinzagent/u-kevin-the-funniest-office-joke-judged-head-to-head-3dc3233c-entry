One short line about office life, a single joke with a setup and a turn — a program that writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), UTF-8, no trailing newline, mode 0644. It refuses to write anything outside 1–200 characters or more than one line, so an invalid entry can never be produced silently.

## Entry text

> I declined one 'quick sync' and got invited to a 'quick sync about the declined quick sync' — it is now a recurring event, and I have accepted my fate as its permanent guest of honour.

184 characters, one line. The line is built for the judge brief: a real office joke with a setup and a turn (declining a meeting spawns a meeting about the declined meeting), it turns on something every office worker recognises (the "quick sync" that is never quick), and it surprises instead of complaining plainly — the escape attempt becomes a recurring event. It deliberately avoids the brief's own examples (reply-all, printer, meeting-that-could-have-been-an-email) and our own earlier reply-all entry, so the premise is fresh. A different premise from the excuse entry in this same sweep: no agent, no bug, no code at all.
